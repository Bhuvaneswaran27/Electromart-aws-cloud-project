# ElectroMart

ElectroMart is a cloud-based e-commerce backend application built using Node.js, Express.js, and Amazon Web Services (AWS).

## Technologies Used

- Node.js
- Express.js
- Amazon EC2
- Amazon RDS (MySQL)
- Git & GitHub

## Features

- Get Products
- Add Product
- Update Product
- Delete Product

## API Endpoints

GET /api/products

POST /api/products

PUT /api/products/:id

DELETE /api/products/:id

## AWS Services Used

- Amazon EC2
- Amazon RDS
- Amazon VPC
- Security Groups
- IAM
