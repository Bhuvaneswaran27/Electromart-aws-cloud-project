# ElectroMart – AWS Cloud E-Commerce Backend

ElectroMart is a cloud-based e-commerce backend application built using
Node.js, Express.js, MySQL, Docker, and Amazon Web Services (AWS).

The application is containerized using Docker and deployed on Amazon ECS
Fargate. A CI/CD pipeline using GitHub, AWS CodePipeline, and AWS CodeBuild
automates the build and deployment process.

## 🚀 Project Overview

ElectroMart provides REST APIs for managing products and e-commerce
operations. The application connects to Amazon RDS for database storage
and is exposed through an Application Load Balancer.

The Docker image is stored in Amazon ECR and deployed to Amazon ECS Fargate.

Additional API routes are implemented for users, carts, orders, and uploads.

## ☁️ AWS Infrastructure
### Amazon ECS Fargate

Runs the containerized ElectroMart application without requiring
management of EC2 instances for the application containers.

### Amazon ECR

Stores the Docker image generated by AWS CodeBuild.

Example image:
```text
610213206510.dkr.ecr.ap-south-1.amazonaws.com/electromart:latest
```

### Amazon RDS

MySQL database used for persistent application data.

### Application Load Balancer

Distributes incoming HTTP traffic to the ECS service.

### Amazon CloudWatch

Used for application logs and monitoring.

### AWS CodeBuild

Builds the Docker image and pushes it to Amazon ECR.

### AWS CodePipeline

Automates the CI/CD workflow from GitHub through the build and deployment
stages.
